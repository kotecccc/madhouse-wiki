# Автоматическая сводка рейдов

Серверный сбор включается только при настройке `MADHOUSE_GLOBAL_RAIDS_CHAT_ID` в окружении Wiki и работающем Telegram-боте (`TELEGRAM_BOT_TOKEN`). Укажите публичное имя канала, например `@madhouse_wiki_raids`, или его отрицательный числовой ID. Пока параметр отсутствует, сбор и публикация выключены. Бота необходимо добавить в канал администратором с правом публикации сообщений. Бот редактирует только свои сообщения. Настройка и запуск выпуска выполняются отдельно.

Сервер раз в 30 секунд пытается прочитать входящие ожидающие приглашения всех доступных подключённых аккаунтов и уточнить состояния найденных боёв. Занятый или недоступный аккаунт пропускается до следующего опроса. Несколько приглашений на один `battleId` учитываются как один бой. Ведущий и его имя определяются по ответу о бое, не по отправителю приглашения. Отсутствие доступа к бою не считается подтверждением его завершения. Информация доступна только для приглашений, которые увидел хотя бы один подключённый аккаунт, и полученных ответов о бое.

После шести подтверждённых завершений одного ведущего и босса в пределах двух часов появляется строка. Пауза более 30 минут между боями завершает серию. Статусы вычисляются по последнему подтверждённому состоянию, устаревший активный бой показывается как «Нет данных». В течение дня сообщения редактируются каждые пять минут. В полночь МСК создаётся новая сводка, а завершённые данные прошлого дня удаляются из текущего состояния; продолжающиеся серии сохраняют счётчик и активную ссылку на бой. Данные сводки хранятся в зашифрованной таблице базы автоматизации.

Перед отправкой нового сообщения сервер сохраняет контрольную запись. Если ответ Telegram потерян, автоматическая повторная отправка блокируется, поскольку сообщение могло быть создано. Для восстановления оператор должен сначала проверить канал и вручную сверить состояние; без этого нельзя безопасно отправлять повторно. Успешные изменения существующего сообщения можно повторять. Сообщение ограничивается по длине; при переполнении указывается количество оставшихся строк. Клан показывается только при наличии проверенных данных; в текущей версии он не определяется.
